SYS-01 // THERMAL ENGINE v1.0.0

HANKO Thermal Suite

Industrial Windows hardware telemetry and powercfg thermal policy instrument modeled after FanControl and HWiNFO64. Probes live CPU, GPU, and ACPI sensors, controls PROCTHROTTLEMAX, PERFBOOSTMODE, and SYSCOOLPOL, inspects nvml.dll PWM locks honestly, and verifies cooling response with a multi-core load worker.

  • Python
  • CustomTkinter
  • WMI / CIM
  • powercfg
  • NVML / nvidia-smi
  • multiprocessing
  • PyInstaller

SYS-02 // TELEMETRY OVERLAY v2.0.0

BANKO

Universal Windows 10/11 GPU, CPU, and RAM performance monitor and one-click gaming optimizer across HP, Dell, Lenovo, ASUS, Acer, MSI, and custom builds. Supports NVIDIA, AMD Radeon, and Intel Arc/Iris telemetry, a draggable semi-transparent Mini Overlay, DWM FPS readout, and Boost System tuning.

  • Python 3.12
  • CustomTkinter
  • psutil
  • WMI / CIM
  • DWM Timing API
  • nvidia-smi
  • Pillow
